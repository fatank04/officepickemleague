# Outbound Sequence Copy — Founding Season 2026 (v2, offer-CTA rebuild)

Three-step sequence for Instantly, ~10 days. Voice: cheeky epic-mundane, blue-collar, "fall"
never "autumn". Send from lookalike domains (getofficepickem.com / tryofficepickem.com), NEVER
the main domain. Plain-text look (no HTML templates) — deliverability + reads like a person.

**v2 changes (2026-07-17):** every CTA is now an OFFER (concierge setup), not a meeting ask —
Gong's research: direct meeting-request CTAs cut replies ~44%; offer-CTAs outperform even
interest CTAs. "Free to start / pay nothing today" is now stated explicitly in every email —
it was missing from v1 and it's the strongest lever for the leagues-live goal. Keep email 1
under ~90 words of body.

Variables from the refinement schema: {{firstName}}, {{company}}, {{personalLine}},
{{tierPrice}} (from headcount), {{cityTeam}} (Steelers for wave 1).

CAN-SPAM footer on every send: real physical mailing address + one-line opt-out
("Not your thing? Reply 'pass' and that's the last you'll hear from me.").

## Reply playbook

- **Positive / "yes" / company size given** → build the league SAME DAY, reply with the invite
  link + 3-line commissioner cheat sheet. Offer a 15-min walkthrough only if they hesitate.
- **"How much?"** → answer in-thread with their exact tier, link /pricing, restate free-to-start
  + Week-8 guarantee. No gating.
- **"Not now"** → "Totally — leagues can start any week; scoring just begins where you join.
  Want me to ping you before Week 4?" (mid-season re-touch list)
- **"Who is this?" / suspicious** → real name, link to officepickemleague.com, note the kits'
  physical address matches the footer. One human, no pressure.
- **"pass" / any opt-out** → suppress in Instantly immediately, account-level.

## Rules
- Numbers must match docs/CANONICAL_FACTS.md — never invent or round.
- No fabricated customers/testimonials. Proof = Gallup (cited), the video, the demo league.
- One thread per human; if both a buyer and champion are sequenced at one account, stagger
  starts by 3 days and never reference the other.
- After Sept 9: switch to the mid-season variant of email 3 ("scoring starts where you start").
